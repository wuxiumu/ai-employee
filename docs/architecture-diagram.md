## 数据流向

```
┌─────────────────────────────────────────────────────────────────┐
│                         数据流向图                               │
└─────────────────────────────────────────────────────────────────┘

初始化阶段:
═══════════

  SERVERS数组 ──────→ 渲染工位 ──────→ DOM插入
  (静态数据)            (HTML生成)      (页面展示)
      │                                    │
      │                                    │
      └────────── 页面加载时 ────────────┘


交互阶段:
═══════════

  用户点击工位
       │
       ▼
  openModal(idx)
       │
       ├──→ 读取SERVERS[idx]数据
       │
       ├──→ 构建currentServer字符串
       │
       ├──→ 填充modal内容
       │    • 头像/标题/副标题
       │    • 配置信息HTML
       │    • 资源进度条HTML
       │    • SSL信息HTML
       │
       ├──→ 显示弹窗
       │    layer.classList.add('open')
       │
       └──→ 滚动到弹窗位置


AI分析阶段:
═══════════

  点击"分析问题"按钮
       │
       ▼
  sendPrompt(prompt)
       │
       └──→ prompt包含当前服务器完整信息
            (名称/IP/OS/CPU/内存/磁盘/SSL等)
            
            可用于:
            • 发送到AI接口
            • 复制到剪贴板
            • 显示在控制台


关闭阶段:
═══════════

  点击关闭/点击遮罩
       │
       ▼
  closeModal()
       │
       └──→ layer.classList.remove('open')
```
