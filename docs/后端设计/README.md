## 🔌 API 设计原则

### RESTful 规范

1. **URL 命名**
   - 使用名词复数: `/servers`, `/metrics`
   - 资源层级: `/servers/{id}/metrics`
   - 动作使用 HTTP 方法: GET/POST/PUT/DELETE

2. **HTTP 状态码**
   - 200 OK - 成功
   - 201 Created - 创建成功
   - 204 No Content - 删除成功
   - 400 Bad Request - 参数错误
   - 401 Unauthorized - 未认证
   - 403 Forbidden - 无权限
   - 404 Not Found - 资源不存在
   - 500 Internal Server Error - 服务器错误

3. **响应格式**
   ```json
   {
     "code": 200,
     "message": "success",
     "data": { ... },
     "timestamp": 1704067200,
     "request_id": "uuid-string"
   }
   ```

### 分页规范

```json
{
  "data": [...],
  "pagination": {
    "page": 1,
    "per_page": 20,
    "total": 100,
    "total_pages": 5
  }
}
```

### 错误处理

```json
{
  "code": 400,
  "message": "Validation failed",
  "errors": {
    "cpu_pct": ["Must be between 0 and 100"]
  },
  "timestamp": 1704067200,
  "request_id": "uuid-string"
}
```
